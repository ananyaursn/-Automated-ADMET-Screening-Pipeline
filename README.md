# -Automated-ADMET-Screening-Pipeline
Automated ADMET screening pipeline for AutoDock Vina PDBQT ligands using RDKit. Performs Lipinski, Veber, Ghose, Egan, Muegge, PAINS, Brenk, BBB, P-gp, hERG, Ames toxicity filtering and exports Excel reports with ADMET-passed compounds. :contentReference[oaicite:0]{index=0}
